# Whiteboard

Sometimes, text isn't enough to capture complex ideas. The **Whiteboard** is an infinite spatial canvas built directly into Synabit that allows you to brainstorm, map out systems, and connect concepts visually.

Every board is a file in your vault, alongside your notes.

---

## Spatial Thinking

Pick a tool from the toolbar on the left, then click the canvas to place something:

- **Shapes:** Over a hundred of them, grouped into Basic, Flowchart, Block Arrows, UML, Entity Relationship, Network/Cloud, BPMN, Wireframe/UI and Callouts. Double-click a shape to label it; select it to change fill, border, opacity and text.
- **Text:** A plain text block, resizable, with its own font size, weight and alignment.
- **Mindmap:** Start from a central idea and grow it. With a mindmap node selected, `Tab` adds a child and `Enter` adds a sibling, each level coloured for you.
- **Draw:** A pressure-sensitive pen and a highlighter. The eraser removes the part of a stroke you drag across rather than the whole stroke.

**Draw Connections:** Drag from the edge of any shape to another to connect them. Select a connection to change its style, colour, arrowheads and label, or to bend it around something by adding waypoints.

**Embed Notes:** Drag a note from the Notes tab of the whiteboard sidebar onto the canvas. The card shows that note's text and links back to it, so the board stays anchored to what you have already written. Drag a specific block and the card shows just that block.

---

## Getting Around

- Scroll or pinch to zoom; two-finger scroll to pan.
- The **Pan** tool (`H`) drags the canvas with the left mouse button; in the **Select** tool, the middle or right button does the same.
- Drag on empty canvas with the Select tool to rubber-band a group of items.

## Grouping and Export

Select two or more items and press `Ctrl/Cmd + G` to group them, so that moving one moves all of them; `Ctrl/Cmd + Shift + G` ungroups. **Export PNG** in the toolbar writes an image of the whole board, cropped to its contents.

## Keyboard Shortcuts

| | |
| --- | --- |
| `V` / `H` / `D` / `S` / `T` / `M` | Select, Pan, Draw, Shape, Text, Mindmap |
| `E` | Eraser |
| `Tab` / `Enter` | On a mindmap node: add child / add sibling |
| `Delete` or `Backspace` | Delete what is selected |
| `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` | Undo / Redo |
| `Ctrl/Cmd + C` / `Ctrl/Cmd + V` | Copy / paste an item |
| `Ctrl/Cmd + G` / `Ctrl/Cmd + Shift + G` | Group / ungroup |
| `Ctrl/Cmd + S` | Save now (boards also save themselves as you work) |

## Deleting a Board

Deleting a board from the sidebar asks first, then moves the file to your vault's trash, where you can restore it from Settings. Nothing is destroyed until you empty the trash.
